# flyingtiregames.com

Website for Flying Tire Games, hosted free on GitHub Pages.

- `index.html` — home page (Games)
- `health-fitness/` — Health & Fitness apps
- `<app>/` — one page per game (e.g. `dogzzle/`)
- `privacy-policy/` — privacy policies for every app
- `images/<app>/` — app images (1080 × 1440, 3:4)

To hide an app card until launch, add the word `hidden` to its `<article class="card">` tag:
`<article class="card" hidden>`. Remove it on launch day.
